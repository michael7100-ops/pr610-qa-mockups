What we're doing & why

  1. 1Lead with the personThe member they were trying to reach is at the top — name, age, city, photo. The page is about this person, so upgrading feels concrete instead of like a generic paywall.
  2. 2All three terms, one tap each1 / 3 / 6-month plans are all on the page — no drill-down to pick a term (and the App Store requires every plan shown). Each row is a single tap.
  3. 3Paying is sendingThe header says it once — "your message sends" — and each plan's button is our send icon — the same one used to send a message. One tap = upgrade and the message goes out.
  4. 4iOS follows Apple's rulesTiles map to App-Store products; the total price leads with the per-month underneath. Same layout and logic as web.
